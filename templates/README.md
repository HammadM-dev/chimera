# templates

Shipped workflow templates (`docs/WORKFLOW_SCHEMA.md`-conformant JSON), each
carrying its own `evals[]` array run as a golden eval on every commit — see
`docs/TESTING.md`. Populated starting M4, first real templates land with the
canvas milestone.

The choice of vertical / which 10–15 templates to ship first is an open
decision the master plan reserves for the founder (design-partner recruiting
drives it) — see `docs/ROADMAP.md`'s note against M4-9. Not decided here.
