# sidecar

Empty placeholder. This becomes the Rust native-control binary at M8 — screen
capture, input injection, and the UI Automation tree on Windows first, spawned
by the Electron main process and driven over line-delimited JSON on stdio.

Rust is confined to this directory and nowhere else in the codebase. See
`docs/ARCHITECTURE.md` (process model) and `docs/ROADMAP.md` M8 for scope.

Not before M8. Do not add code here during M0–M7.
